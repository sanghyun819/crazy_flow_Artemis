# 7게이트 TOGT 계획 결과

![TOGT 경로](seven-gates-togt-path.png)

사용자가 제공한 [7게이트 배치](../config/seven_gates.yaml)를 기준으로 `/home/sh/togt_ws`의 TOGT `RacePlanner::planTOGT()`를 실행했다. 시작·종료 위치는 `(1.5, -2.0, 1.25)`이며, 정지 상태에서 출발해 G1 → G2 → G3 → G4 → G5 → G6 → G7 순서로 한 번씩 정방향 통과하고 같은 위치에서 정지한다. 이륙·착륙 구간은 계획에 포함하지 않았다.

결과는 약 **21.41 m / 17.63초**, 16개의 7차 다항식이다. TOGT의 연속 경로 형상에 시간 배율 1.03을 적용했다. 이는 시간 최적화를 수행한 국소해를 선택한 속도 제한에 맞춰 재조정한 결과이며, 전역 최단시간을 보장하지 않는다.

## 적용한 기체와 제약

| 항목 | 적용값 / 근거 |
| --- | --- |
| 기체 모델 | Crazyflie `cf2x_L250`, 기존 TOGT Crazyflie 파라미터 |
| 질량 | 0.0319 kg |
| 관성 대각성분 | `[16.8, 16.8, 29.8] × 10⁻⁶ kg·m²` |
| 모터 축별 모멘트 암 | 0.03253 m; 기존 모델의 추력 배분 행렬 유지 |
| 모터별 추력 범위 | 모델 0.0128176–0.120 N, 계획 상한 0.112 N |
| 중력 | TOGT 코드에 실제 사용된 9.8066 m/s² |
| 기하 모델 | 설정의 반경 0.06 m 구형 기체 외피 |
| 프레임과 기체 외피 사이 여유 | 최소 0.10 m |
| 개구부 / 기체 중심 유효창 | 0.50 × 0.50 m / 0.18 × 0.18 m |
| TOGT 제약창 | 0.14 × 0.14 m; 유효창 안쪽으로 추가 0.02 m/면 예약 |
| 게이트 방향 제약 | 중심 앞뒤 0.30 m에 입·출구 제약창 |
| 속도 / 틸트 | 1.5 m/s / 35°, 실내 계획용으로 선택한 제한 |
| 바디 각속도 | XY 노름 ≤ 4 rad/s, Z 절댓값 ≤ 2 rad/s |
| 수평 벽 여유 | 기체 외피 기준 1.5 m 이상 |
| 위치 계획 범위 | X `[-2.44, 2.44]`, Y `[-3.94, 3.94]`, Z `[0.25, 1.70]` m |

질량·관성·모터 배분은 `crazyflow/crazyflow/drones/params.toml`의 `cf2x_L250` 및 `/home/sh/togt_ws/parameters/crazyflie/crazyflie_quad.yaml`을 대조했다. 반경 0.06 m는 사용자가 제공한 게이트 설정값이며 실측 외피 인증값은 아니다. 모터·추정기·프로펠러 구성이 다른 기체에 자동으로 적용되지는 않는다.

게이트 `yaw_deg`는 CW이며 법선은 `(cos(-yaw), sin(-yaw), 0)`이다. TOGT 프리즘은 로컬 +Z에서 -Z로 입·출구를 생성하므로, `rpy=[0, -90, -yaw_deg]`를 적용해 로컬 +Z가 **통과 법선의 반대쪽**을 가리키게 했다. 게이트 방향은 이동 방향이고 기체 yaw 명령과 다르다. 계획·독립 동역학 검증의 pre-tilt yaw는 0으로 고정했다.

1번에서 2번으로 이동할 때 4번 프레임을 스치지 않도록 `(0.60, 0.65, 1.25)` 주변 반경 0.05 m 구를 우회 제약으로 추가했다. 실제 게이트 위치는 변경하지 않았다. 5번 통과 후 북쪽에서 내려와 6번을 반대 방향으로 통과한다.

## 검증 결과

- G1–G7 순서·정방향·한 번씩 통과 확인. 개구부 평면과 다항식의 교점을 직접 계산했다.
- 구간 이음부의 위치·속도·가속도·jerk 연속성 및 정지 출발·종료 확인.
- 최고 속도 **1.457 m/s**. 위치 범위와 속도 최대값은 다항식 극점으로 검사했다.
- 모든 프레임과 기체 외피 사이 최소 여유 하한 **0.120 m**. 원하는 통과 게이트 외의 프레임도 전체 경로에서 검사했다.
- 기체 외피와 벽 최소 여유 **1.796 m**, 천장 약 **0.51 m**.
- 1 kHz 동역학 검증에서 최고 틸트 **18.94°**, 모터별 추력 **0.07074–0.08907 N**.

프레임은 개구부 외곽의 폭 0.08 m인 네 개 직육면체로 모델링했다. 깊이는 별도 수치가 없으므로 **0.08 m로 가정**했다. 기체 중심-프레임 거리의 표본 최솟값에서 `기체 반경 + 최대속도 × 최대 표본간격 / 2`를 빼서 표본 사이도 포함하는 보수적 여유 하한을 구한다. 각 다항식 이음부의 양쪽도 검사한다.

동역학은 강체·무항력·순간 추력 모델이다. 항력, 모터 지연, 배터리 전압 감소, 추종 오차를 포함한 폐루프 시뮬레이션이나 실제 비행은 수행하지 않았다. 동역학 최대값은 표본 검사이며 연속시간 인증값이 아니다. 기체 반경·프레임 깊이를 변경하면 다시 검증해야 한다.

## 산출물

- [togt_polynomial.csv](../results/seven_gates/togt_polynomial.csv): 최종 다항식. `duration` + X/Y/Z/yaw 각각 8계수, 33열. 계수는 구간 로컬 시간의 오름차순. 절대 world 좌표, 시작 위치 오프셋 포함.
- [togt_samples.csv](../results/seven_gates/togt_samples.csv): 최종 다항식에서 다시 계산한 약 1 kHz 위치·속도·가속도·jerk·snap·wxyz 자세·바디 각속도·모터별 추력.
- [audit.json](../results/seven_gates/audit.json): 원본 게이트 설정, 적용 모델, 검증 결과, 입력·출력 SHA-256 해시.
- [track.yaml](../results/seven_gates/track.yaml): TOGT 입력 트랙.
- `togt_raw_polynomial.csv`, `raw_audit.json`, `solver.log`: 시간 재조정 전 결과와 원본 검증 기록. 최종 사용 파일과 구분할 것.

다항식 열 배치는 Crazyswarm 업로드 포맷과 같다. 이 저장소는 기체에 업로드하거나 비행 명령을 보내지 않는다. 자세와 yaw 정의의 일치 여부는 컨트롤러 연결 시 확인해야 한다.

## 재현

```bash
cd /home/sh/crazy_ws/crazyflie-gate-route
python3 scripts/plan_seven_gates.py --togt-dir /home/sh/togt_ws
MPLCONFIGDIR=/tmp/gate_layout_mpl PYTHONNOUSERSITE=1 \
  /usr/bin/python3 scripts/plot_togt_path.py
python3 -m unittest discover -s tests -v
```

계획기는 C++17/Eigen3 및 기존 TOGT `build-core/libdrolib.a`를 사용한다. 소스 코드는 `togt/plan.cpp`이며 생성 바이너리는 Git 제외된 `build/`에 저장된다. 현재 환경의 중복 Matplotlib 설치 충돌을 피하기 위해 시각화 예시는 시스템 Python 패키지를 선택한다. 일반적인 단일 환경에서는 `python3 scripts/plot_togt_path.py`로 실행 가능하다.

기하 검증 실패 시 최종 파일을 생성하지 않고 종료한다. 동역학 제한만 초과하면 형상을 유지하며 시간을 늘리고 모든 검사를 다시 수행한다. 재계산 실패 후 과거 최종 파일이 남아 있을 수 있으므로 성공 종료와 `audit.json`의 해시를 함께 확인해야 한다.
